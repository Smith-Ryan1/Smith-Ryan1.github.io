Mesh topography is typically used in wide access networks and is a result of each node being linked to one another, while this useful for making all data immediantly transferable without the need of a central hub, it is more challenging to ensure each node is corrected properly and, as such, more difficult to scale.
Star topography features a central node, or hub, that is the middle man for data going from one hub to another, which is ultimately slower. This is more scalable as each node only needs to be connected to the central hub, thus allowing for easier changes. This is more commonly used in LANs.

As for the differnces between switches and routers, similarly to the differences between mesh and star topography, Switches are used in LANs, whereas routers are used in WANs, linking devices to the internet.
