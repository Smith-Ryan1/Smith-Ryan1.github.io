|acronymn| what it is|
|----|----|
|CMOS| Complimentary metal oxide semiconductor, what bios settings are stored in provided by the motherboard manufacturer.|
|BIOS| basic input/output system|
|POST| power on self-test|
|UEFI| Unified Extensible Firmware Interface, runs with BIOS and addresses security issues legacy BIOS systems had.|
|RDP| Remote Desktop Protocol- Allows you to access applications remotely.|
|FTP| File transport Protocol- transports files, uses TCP ports 20 and 21, 20 is used for sending control commands, 21 is used for transfering data.|
|TFTP| Trivial file transport protocol, simpler than FTP, only uses UDP port 69 and is not good for large data transfers, though it is useful for LAN transfers.|
|HTTP| used as the protocol for almost all web browsers on the internet. Uses TCP port 80|
|SSH| Secure shell used to connect a device across a network using the command line interface, uses TCP port 22, provides an encrypted channel for both server and client
|TelNet| same as SSH but used TCP port 23, it is unsecure so it should be used with caution.|
|SNMP| Simple Network Management Protocol, used to monitor and manage Network devices, gathers statistics about network devices, uses UDP ports 161 and 162.|
